# شجرة عائلة الماجد — الأحساء

موقع شجرة العائلة: https://hsnalmajed.github.io/almajed-family-ahsa/
لوحة المدير: https://hsnalmajed.github.io/almajed-family-ahsa/admin.html

## التقنيات
- صفحات ثابتة (HTML / CSS / JavaScript) مستضافة على GitHub Pages.
- قاعدة البيانات: Firebase Firestore (مشروع `family-tree-hasan`) مع تحديث لحظي.
- دخول المدير: حساب Google فقط (البريد المسموح في `firebase-config.js` و`firestore.rules`).
- حماية إضافية: Firebase App Check (reCAPTCHA Enterprise).

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html`, `app.js` | الصفحة العامة: الشجرة، البحث، صلة القرابة، طلبات الإضافة والتحديث |
| `relationship.js` | حساب صلة القرابة بين شخصين |
| `bizextras.js` | العلامات التجارية لأبناء العائلة (الفروع، المتاجر، روابط أخرى) |
| `admin.html`, `admin.js` | لوحة المدير: الطلبات، كل الأشخاص، شجرة المدير، البطاقات، جمع البيانات، السجل |
| `reception.js` | تبويب الاستقبال في اجتماعات العائلة (تحديث بيانات الشخص وأسرته بزر حفظ واحد) |
| `attendance.js` | تبويب الحضور (من حضر الاجتماع ومن لم يحضر) |
| `firebase-config.js` | إعدادات Firebase العامة وبريد المدير |
| `firestore.rules` | قواعد حماية قاعدة البيانات (تُنسخ إلى Firebase Console ← Firestore ← Rules) |
| `sw.js`, `manifest.json` | تشغيل الموقع كتطبيق على الجوال |
| `style.css` | التنسيقات |

## الحماية (ملخّص)
- الزوار: قراءة الشجرة فقط، وإرسال طلبات تُراجَع من المدير. لا يرون إلا آخر 4 أرقام من الجوال.
- أرقام الجوال الكاملة في مجموعة منفصلة `personsPrivate` لا يقرؤها إلا المدير.
- أي إضافة أو تعديل أو حذف مباشر: للمدير فقط (حساب Google المسجّل، بريد مؤكَّد).
- سجل نشاط المدير `adminLog` يُضاف إليه فقط ولا يمكن تعديله أو حذفه.
- كل النصوص القادمة من المستخدمين تُعرض بعد تنظيفها (حماية من XSS)، والصور تُقبل فقط إن كانت صوراً حقيقية.
- لا يُجمع تاريخ الميلاد في الموقع.

## ملاحظات
- مفتاح `apiKey` في `firebase-config.js` مفتاح عام بطبيعته في تطبيقات Firebase للويب، والحماية الفعلية في `firestore.rules` وApp Check.
- لا يوجد في الكود أي كلمة مرور أو مفتاح سرّي.
- لإضافة مدير: أضف بريده في `ADMIN_EMAILS` داخل `firebase-config.js` وفي `adminEmails()` داخل `firestore.rules` ثم انشر القواعد.
